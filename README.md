# Eddy Eder portfolio prototype

This is the first static prototype for the connected Eddy Eder, WaMü / Allesandersstadt, Sustainable Reflecting, and Peaceful Demonstrator Study web presence.

Open `index.html` in a browser to review the current design. The site uses plain HTML, CSS, and JavaScript so it can be hosted free on services such as Cloudflare Pages or GitHub Pages.
